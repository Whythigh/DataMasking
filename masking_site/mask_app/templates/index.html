Three steps, no configuration

Upload, mask, download. Or call the API and skip the browser entirely.

1

Send your file

Drop in a CSV, Excel or XML file through the browser — or POST it to the API from your own pipeline. Multi-sheet workbooks are handled in one pass.

2

Personal data is found automatically

Column names and cell values are both scanned to identify names, emails, phone numbers, bank details and ID numbers. You can force-include or exclude any column.

3

Get a safe file back

Personal data is replaced with realistic substitutes. Amounts, dates and categories stay untouched. The same person gets the same replacement in every sheet, so relationships between tables survive. A summary sheet lists exactly what changed.

Common questions

The things people ask before trying it.

Can masked data be turned back into the originals?

No. The substitution is one-way and no reverse mapping is stored. Once a file is masked, the original identities can't be recovered from it — that's the whole point.

Will masking break my analysis?

It shouldn't. Amounts, dates, categories and codes are left untouched — only identifying fields are replaced, and they keep the same shape. If a column gets masked that you needed intact, you can exclude it.

What if it misses something, or masks the wrong column?

Automatic detection is good but not perfect, which is why every file comes back with a summary sheet listing what changed. Through the API you can also force specific columns to be masked or left alone.

Do you store the files I upload?

No. Files are processed in memory and discarded once the response is sent. Usage records keep row counts and column names — never the data itself.

Can this run inside our own network?

On-premise deployment is available for organisations that can't send data to an external service. Get in touch and we'll walk through what your environment needs.
